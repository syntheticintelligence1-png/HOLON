- Plant realistic misimplementations in scratch copies of the real code those documents are extracted from: off-by-one
  offsets, missing clears, wrong masks, swapped cursors, a dropped guard, a reordered write.
- Re-extract with HOLON's own frontends (`python -m holon extract ...`), re-derive and re-run the laws over the mutated
  documents, and record for each mutant whether some law's outcome moves.
- A mutant that changes the code's behaviour but moves no law is an extraction gap or a rule gap: a finding. Say which,
  with the mutant's diff and the commands.
- Adjudicate equivalent mutants from the diff alone, before you run anything.
