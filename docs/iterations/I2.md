# I2: semantic bindings and dependency index

Plan: `docs/BUILD_PLAN.md` §4 I2 (debt D-h). Prompt: `prompts/I2_bindings.md`. Preregistration: `spec/M2/predictions.json` key `I2`, committed in `37aff4c`. Implementation: `784ade2`, followed by the review fixes.

## Done

- **Kernel-form bindings.** `holon/bindings.py` has the pinned checker translate each generated model to BendTT (`bend model.bend -o model.bendtt`).
  - The translation covers every definition and datatype the model uses, Base included. Locals are alpha-normalized and every reference is resolved.
  - The kernel cone of a law is the closure, over that graph, of the `M.<name>` references of its emitted statement. Constructor tags map to the datatype whose `Σ` enumeration declares them, and dotted names resolve by their longest prefix.
  - Each law is bound (`spec/bindings/<m>.json`) to three things: the sha256 of every definition in its cone, the sha256 of its emitted statement, and the sha256 of its emitted counter-law. Comment lines are removed before hashing.
  - An `M.` reference that resolves to nothing, a definition BendTT leaves out of scope, an empty cone, or a model definition named like a kernel local is an error.
- **Generated indexes**, both compared by G1:
  - `gen/<m>/model/<model>.defs.json`: the kernel index;
  - `results/<m>/deps.json`: definition → laws, by bare name and per model (the stale index).
- **G2** re-derives the bindings from the committed models and the current emitter. It also checks that the `LAWS.bend` Bend accepted is exactly the bound emission for the law's status: the statement for PROVED, the counter-law for REFUTED. A mismatch names each law and definition.
  - A renamed local or an edited comment changes nothing.
  - A changed definition fails exactly the laws that reach it.
  - An emitter that adds a premise fails exactly that law.
- **Bind channel.** `holon bind` logs every write to `spec/bindings/changes.jsonl`. It refuses to change a binding without `--accept-change "<reason>"`.

## Surprises

1. **The binding did not cover what the emitter prints (review finding, high severity).** The first binding pinned the statement hash and the model cone, but not the emitter's own output. That output includes the law-local `pin_h` and the View types. The reviewer patched the emitter to add a premise, and every gate check passed: G1 because both sides regenerate with the same emitter, G2 because the IR and model were unchanged.
   - The fix binds the emitted statement and counter-law, and checks that the accepted `LAWS.bend` equals the bound emission.
   - The rebind went through the logged channel, and no law's cone changed.
   - BUILD_PLAN listed `generator_sha256` in each binding. My prompt dropped it, and it is still not bound: the emitted text covers the meaning, and a refactor with identical output changes nothing. The records carry it for G1.
2. **Two deviations from the plan, both on purpose.**
   - The bindings live in `spec/bindings/`, not `laws/M0/BINDINGS.json`, because AGENTS.md forbids adding files under the frozen `laws/M0/`.
   - The dependency index comes from the checker's BendTT translation, not from the generator's def list. That makes it independent of HOLON's own text.
3. **I2-P1 to P3 were already recorded at prereg time.** The I1 token cones in the records give those dependent sets, and I2-P4 implies them. They count as construction checks, not predictions. Only P4, and the G2 half of P5, test anything new.
4. **The I1 promise to replace the token cone was not kept.** I1 said I2 would replace the token cone. Instead, records keep the token cone, and the BendTT cone cross-checks it (I2-P4). The docstrings now say so.
5. **More review findings, all fixed.**
   - Universe levels were read as constructor tags, adding a false edge from every type to `List`.
   - `opaque` entries were not parsed.
   - Dotted roots resolved to their type.
   - Unresolved roots and "out of scope" were dropped silently.
   - `deps.json` merged same-named definitions of two models.
   - G1 reported a `deps.json` mismatch as a summary mismatch.
   - Errors named a temporary file.
   - Creations were not logged.
6. **The initial binding (`784ade2`) was written before creations were logged**, so `changes.jsonl` begins with the review rebind.

## Not done

- **Proof-only dependencies.** `deps.json` marks stale only the laws whose statement cone reaches a definition. A model change that breaks only a proof is caught by G5's re-check and G1's regeneration, not by the stale index. The review raised this and rejected it as a defect; it is noted here.
- **Binding changes are not cross-checked against git.** The audit does not yet verify that every git change to `spec/bindings/<m>.json` comes with a matching `changes.jsonl` line. That is planned with I10.
