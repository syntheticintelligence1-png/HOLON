## What was built

The rules are unchanged. Each fallback has one opt-in, which the composed driver sets from the protocol's
`document_fallback`; without it every output is as before, byte for byte (P8; Morph's sidecars and every earlier
protocol name none).

### (C) Coverage: `holon coverage --typed-only` (protocol `document_fallback.coverage "typed_only"`)

Only with `--sidecars` (the composed route's form; without it, exit 2). A given extraction sidecar is not walked when
its document is not a file under the root (`not_extracted`: the frontend refused it) or is listed in
`gen/<M>/sorts/opaque.json` (`opaque`: I111's O2-O7). It is listed under the report's `skipped [{document, reason}]`,
a key written only under the flag. Every other sidecar is walked as before; an extracted, typed document whose walk
refuses still refuses the stage.

### (R) The runners: `holon_run._run_per_document` (protocol `document_fallback.run "unknown"`)

A runner group whose `holon run` exits non-zero is re-run once per law document (sorted), with the group's own
arguments. A document whose re-run exits 0 keeps its records. A document whose re-run fails falls back: every law of
the group over it gets the fallback record (UNKNOWN, no witness, kernel and checker `not_run`, no law or proof file,
attempts `[{kind: document_fallback, stage: run, runner, error}]`). It is a refusal of the group (no record kept,
`milestone_refusal`) when the first run or a re-run exits 2, or when at least two documents all fail with the same
last line once law ids and document paths are masked. The runner aggregates add `fallback_documents` and
`fallback_laws`.

### (B) The binding: `holon bind --unbound document` (protocol `document_fallback.bind "unknown"`)

I115's `--unbound skip`, plus: an exception other than `BindingError` raised while binding a law over document D, whose
model (`holon.bindings.model_path`) no law over another document shares, unbinds every law over D with
`document fallback: <class>: <message>` and records D in `spec/bindings/<M>.fallback.json`. Any other failure refuses
(exit 1, nothing written): the configuration, loading the laws, a law with no document, or a model shared across
documents. `binding_check` (I115, unchanged) then rewrites every decided record over D UNKNOWN.

### (3) The evidence schema

`spec/schemas/evidence.schema.json` gains the optional `fallback` (an array of `{document, sha256, model, class:
e2_unmapped, error}`, exactly those keys). Every committed evidence set validates and is unchanged (P7); the frozen
`schemas/` is untouched.

### (2) The per-family record: `tools/i118_families.py`

A measurement outside `holon/`. It reads only pre-decision outputs of each row (derive's `DERIVATION.json`, types,
opaque, DISCH closure, evidence, the generated undo and fact sidecars) and records per (rule, subform) of the catalog
the laws derived, the family's input counts and a reason (`derived`, `no_input`, `input_no_law`, `part_absent`,
`unmeasured`).

## What a fallen-back document contributes, and what other documents may assume

- **(C)** A skipped document has no coverage entry. No law is over it (not extracted: no document; opaque: no typed
  model), so no record reads its entry. Other documents' entries are computed exactly as before.
- **(R)** A fallen-back document contributes no decision in that runner. Each document's re-run reads only its own
  laws, so every other document's laws are decided exactly as a run of those laws alone (P3: Counter's records equal
  the unfaulted run's).
- **(B)** A fallen-back document's laws are unbound, so none of their decisions is admitted. Every other law is bound
  by the same `bind_law` (P5: Counter's bindings equal the unfaulted run's).

## Soundness

Every fallback only removes claims or decisions, never adds them.
- **(C)** skips accounting for documents no law is over. Coverage is reported debt, never a premise.
- **(R)** replaces a failed runner's output for one document by UNKNOWN records. A re-run decides a law only as the
  runner decides it alone, through the same checker, so no law becomes PROVED that the runner would not prove. The
  constrained shape (P3) checks it: the control decides laws over Guarded; with the fault, none over it is decided.
- **(B)** unbinds laws; `binding_check` only refuses decisions of unbound laws (P5: every decided record over Guarded
  becomes UNKNOWN).
- **Not confined** failures stay refusals (P4, P6), so a fallback never hides an input that is wrong for every
  document.
- **Every REFUTED still needs its replay.** Route A's replay and filter are unchanged; a REFUTED on deployed code, or on
  corpus code outside Q56 (4)'s exemption, is handled under Q56.
