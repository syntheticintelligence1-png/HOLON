## Done

- **Non-vacuity (`holon/inhabit.py`, gate G11V).** Every record carries `non_vacuity`.
  - **The 9 premised PROVED laws** have dual-checked inhabitants in `gen/<m>/<law>/nonvac/`. Each inhabitant is generated from the parent's frozen IR: the binders become existential and the premises become the claim, emitted by the same emitter. Its witness comes from the compiled model's search.
  - **The 6 premised REFUTED laws** count through their accepted counter-law witnesses. The other laws have no premises.
  - **What G11V checks:** it regenerates each inhabitant's `LAWS.bend` from the IR and its `PROOF.bend` from the recorded witness, and compares whole files. The directory must hold exactly those two files. Where states are involved, the inhabitant must be reachable (`run(p, s0)`), and for two states it must be non-degenerate, as decided by the compiled model.
- **Reachable inhabitants.** Every M1 inhabitant is a set of traces from `s0`:
  - `L_undo_CSR`: `[commitBatch(post 110), revertBatch, sendMessage]` against `[sendMessage, commitBatch(post 111), revertBatch]`. The two states differ only in the committed-state-root residue.
  - `L_undo_BD`: a `commitBatch` against a `commitBatchWithProof` of the same batch, each reverted. The two states differ only in the batch-data residue.
  - `L_disch_stale` and `L_disch_stale_commit`: `run([commitBatch, challengeState(1), wait 11], s0)`, with a permitted or proof-backed action.
- **D2 (`holon/oracles/zero_blob.py`).** `0x01 ‖ sha256(0xc0 ‖ 0^47)[1:]` equals ZERO_VERSIONED_HASH (Rollup.sol:25) and EmptyVersionedHash (common/blob/payload.go:22). It is checked on a clean checkout at the target commit, and the result (`checked`) is in `results/M2/hypotheses.json`.
- **Checker pin.**
  - `bend.fingerprint()` covers the resolved checkout's HEAD, every `.ts`, `.lean` and `.bend` file under `bend2/`, the bun version and the bun binary's sha256.
  - `run()` executes exactly the fingerprinted command (`[bun, main.ts]`), and GENV verifies that the two are identical. `~/.elan/bin` is appended to PATH, not prepended.
  - The cached BendTT kernel binary is pinned (`bend.pinned_kernel_sha256`).
  - GENV refuses: a fingerprint mismatch, an unresolvable override, a global bunfig, a `BENDTT` override, and a quarantine.
  - The checker runs with `BEND_NO_TELEMETRY=1`, and without `BUN_OPTIONS`, `BUN_CONFIG_*`, `BEND_LIB` or `BEND_HUB`.
- **Quarantine, budget and upgrade.**
  - An accepted canary writes `results/quarantine.json`, an agent-writable tripwire, labelled as such.
  - G5 enforces a 120 s per-file budget and writes `results/<m>/gate_timing.json` (ignored by git and by G1).
  - `python -m holon checker-upgrade` runs the gates under a candidate checker in a scratch copy and reports every record diff. Dry run to the current fingerprint: zero diffs.

## Surprises

1. **The explorer reported reachable states as constructed ones,** so "reachable" could not be read off a witness. It now reports `run(p, s0)`. That exposed a latent bug: the explorer's equality used `JSON.stringify`, so key order decided equations. A counterexample read back from a report has sorted keys, while a recomputed state has the model's field order. `tests_m1`'s independent canary re-check then failed 12 times. Equality is now canonical, and all records are unchanged (`6def4a7`).
2. **Perturbations were ill-typed.** The explorer filled an empty list of records with numbers when perturbing a state. Perturbations now follow the declared field types.
3. **Review findings, one high, 15 of 21 confirmed.**
   - **High: pin bypass.** The fingerprint resolved `bend` with the process PATH, but runs used a PATH with `~/.elan/bin` prepended, so a planted `bend` ran unpinned while GENV passed. The agent demonstrated this against the old code. It is fixed: the gate fingerprints and executes one resolved command.
   - **Medium: G11V was textual.** Commented-out pins, or a doctored model imported by the inhabitant, passed. G11V now regenerates and compares whole files.
   - **Medium: bun was pinned by its version string only.** Its bytes are now hashed.
   - **I3-P4's test could pass for the wrong reason.** Any compile failure in a temp directory also produced `unknown`. It was strengthened, with an amendment logged in `spec/M2/amendments.jsonl`.
   - **The UNDO inhabitants were unreachable**, against the plan's goal. They are now reachable. Dropping unconstrained binders from the search took `L_undo_BD` from 225 s to under 1 s.
   - **Smaller fixes:** the zero-blob check now ties itself to the target commit; the docs and the ledger were updated; the wording marks self-certified tripwires as such.
4. **I1 test amended.** The I1 test that asserted `non_vacuity == "pending:I3"` was amended, as §0.1 requires: the iteration that fills a pending field removes its pending value.

## Not done

- **The kernel's first build is unpinned.** GENV checks the kernel only from the run after the one that builds it.
- **D2 is not regenerated automatically.** `results/M2/hypotheses.json` is refreshed by `python -m holon oracle zero-blob`; no gate check regenerates it. Hypotheses become G11V inputs in I12.
- **The M0 inhabitants add little beyond the pin mechanism.** M0 premises are pins, which the emitter already guarantees consistent. The inhabitants confirm that the pinned values are representable through the getters, and not much more.
