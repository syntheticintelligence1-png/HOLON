## Surprises

1. **Stored-state name collision in the shared evaluator (the cause of the builder's failed inhabitants).** All
   models of a document share one node process (`holon/js/eval3.mjs`), whose `STORE` is keyed by the save name alone.
   `S3.Model.fresh` names states `g1, g2, ..` per model, so every witness `settle` (a fresh model) overwrote the
   states the shared exploration had stored under the same names. A law decided after a settle then evaluated a
   different state than its trace; the rev_132 / rev_213 inhabitant files failed at `cz`. Fixed in
   `holon/disch/run.py` (`Doc.factory` prefixes the names with the model's `tid`). The builder's diagnosis was right.
   The same pattern may exist wherever I30's `holon.sorts` code creates several models on one evaluator; I31 does not
   touch `holon/sorts` (out of scope, reported).
2. **The builder's settle change wrote into the caller's steps.** Its uncommitted fix made an inhabitant keep the
   hints' answers by mutating the steps passed in, which the exploration may still hold (a later witness could then
   carry stand-in answers). The finisher kept the intent and moved it to one private copy of the steps.
3. **A non-preregistered last-step cap was removed.** The builder had added `LAST_STEP_STATES = 40` (the last step
   synthesized only from the first 40 B-states). That searches fewer prefixes than the sidecar's budget names, so
   the finisher set it to None (every B-state the preregistered budget reaches). Cost: a longer run.
4. **Run time under contention.** The full run took far longer than the builder's ~72 minutes (68 minutes for the
   exploration alone at load 12-19), and did not finish in the time box.
5. **The renaming test cannot pass for any implementation** (Questions 2). Confirmed by the finisher.
6. **Gates.** The frozen suite has one failure, `tests/test_40_gate`: M0 gate G7, Lean over its 120 s budget
   (182.4 s and 121.3 s) under load 18; every other M0 check passed. M1 and M2 gates fail only at G1, records
   differing in `generator_sha256` (Questions 3).
