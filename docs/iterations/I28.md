I28 builds `holon versions`, a model of the Rollup's deployed upgrade path, V3 to V11, as one machine with migration steps.

- **Model:** one model3 module per version, and a layer over them.
- **The law:** rule PAR's new sub-form `init_chain` derives the initialization-coherence law O9. It is decided over that
  machine.
- **Replay:** both the upgrade path and the witness run on the real code.

The key is `iterations.I28` in `spec/M3/predictions.json`. The contract is the docstring of `tests_m3/test_versions.py`
(V1-V9, PI1-PI6, S1-S3, G1-G3, the commit rules). It was committed in `295cf437` (C_K), and merged with its review as
`089b43a4`. No outcome was observed before C_K, so all six predictions count.
