# I72 (I33's evidence key): E2 over the adopted holon-facts/0.3 transitions documents. P1 held (recorded, not counted)

I72 gives the adopted Rollup document's model I14's level E2 ("written via p, read via q") in M2's and M3's evidence
sets, computed from the document's own terms. Until now the model had anchors only (I20). E1-E6 were defined over facts
0.1 and 0.2 diagrams, so a law over the adopted document that names an action could claim no computed level, and GEVID
would refuse I33's O12 contract on M3, which claims E2.
- **The rule** (Z1-Z3):
  - Accesses are (family, path) pairs, from the document's write records and its maximal selection chains over state
    terms.
  - Threading positions are not reads: post[f], and loop carried/next/at_break/exit entries named ["storage", f].
  - Overlap separates paths only by member names and distinct literal keys.
  - There is one atom per (p, q, family), p == q included, via {carrier, writes, reads}.
- **Where** (Z4):
  - Atoms are computed only in a target milestone's build, from the committed diagrams with adopted documents on.
  - The schema's atom model and id patterns admit the adopted model key (a dot after the first character).
- **Result:**
  - Each set has 421 E2 atoms over 25 families, 55 of them relating an action to itself, exactly the instrument's.
  - No law's evidence moved.

The key is `iterations.I72` in `spec/M3/predictions.json`. The contract is the docstring of
`tests_m3/test_e2_transitions.py` (Z1-Z7). It was committed in `afee7f8` (C_K) on `2d173e3`, and merged with the
review fold as `4ba76b9`.

**Nothing is counted** (`thresholds.counted_predictions` is empty). P1 is entailed by R3 and R4, the instrument's
inventory was known at the prereg, and the prereg review's simulated build observed it (`thresholds.disclosure`).
