## Surprises

1. **Blind derivation reproduces the lead's statements.** With the corrected brief, the session authored its own
   DISCH, UNDO, FACT, OWN and typed-sorts sidecars from the code. Every law derive wrote is one of the lead's
   statements: 195 of 257, none blind-only. Where the inputs are code, derivation looks reproducible from the
   code alone.
2. **No record can be written from the pack.** Every record's `model_assumptions` field comes from HOLON's assumption
   ledger (`spec/ledger/assumptions.json`), and `records.v2_fields` refuses without it. A metadata file outside the
   pack blocks status recording, so I82's status metric cannot run on a blind tree.
3. **Run 1's brief omitted generator steps,** most decisively `holon disch` (amended for run 2). Derive's typed part
   couples PAR's laws to DISCH's sidecar.
4. **The preregistered reads scorer judges text,** so it flags patterns, scripts and the brief's own config rewrite.
   The amended scorer fails to parse one command with an unbalanced quote, which it reports.
5. **Run 2 filled the disk** with 1.2 GB of Go caches inside W. They were deleted after the session.
6. **Each session's shell started in `/home/user/HOLON`.** The `cd W && ` rule kept every command inside W.
7. **The leak list grew from 327 to 450 matches** between I82's pack and `<P>`.
