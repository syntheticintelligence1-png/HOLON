## Soundness argument

- `lin(t, opaque=True)` reads every op and unop term as an atom of its own. So the linear forms of a fact set under
  the rule are a coarsening of those under the old reading. Every implication the opaque Reasoner draws, the old one
  also drew, and an atom is refuted only if it is refuted with arithmetic uninterpreted.
- Uninterpreted arithmetic is sound under any interpretation of + - * << on sized integers, wraparound included. So
  a branch the default prunes is unreachable in Go, and every path the old reading kept is still kept.
- On top of that, the default keeps the branches that only unbounded arithmetic pruned. A site is open wherever only
  unbounded arithmetic called it safe.
- Downstream, a law loses evidence or statement premises it should never have had, or its paths grow. That can make
  it weaker, UNKNOWN or REFUTED. It cannot make a law PROVED that rested on a pruned branch.
- The planted pair shows both halves, and the pinned go 1.24.7 confirms them (P2): Inc64(nil, MaxInt64) panics, and
  Idx(make([]byte,1), MaxInt) panics.
- Every REFUTED still needs its replay. None was produced tonight.
- What the rule loses: coverage only, e.g. `x+1 == x` is no longer refuted.

   Morph documents change (common/batch: the batch cache's capacity and sealing, the data hash, the compressed-size
   checks), and so do 148 of M3's 179 decided laws.

4. The audit tool's law matching was wrong in both directions (above). Counting by decision traces was also
   incomplete: 79 decided M3 laws have no trace. The lead caught this, and Q95's method settled it.
5. Every M3 decision trace already reads `config/holon.json` as changed on the unmodified lead, so `holon land dirty`
   reports all 204 traced M3 laws dirty without any change. That masks real input changes until subtracted.
6. `holon land`'s REGEN list does not include `holon codecs`, so `derive` refuses on a tree whose Go documents
   moved ("gen/M3/codec is stale").
7. The disk filled once, from the audit scratch tree plus the Go build cache. I ran `go clean -cache` (rebuildable)
   while no counted run was going, and archived the audit scratch trees into the vault.
