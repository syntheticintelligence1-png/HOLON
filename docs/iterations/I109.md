The schema `spec/schemas/facts_0_3.schema.json` gains two optional keys: Go `extraction.machines` and Solidity
`extraction.term_budget`.

**(a)**
- **A1, the receiver as an argument.** go/ssa passes a static method call's receiver as `Args[0]`. The method's
  `Function` has it as `Params[0]`, but its signature type does not list it. So when a static callee is a method
  (the dump's `method` flag, else go/ssa's `(T).M` name without `$`) and the call has exactly one argument more than
  the signature, the member's inputs start with the receiver (`"*"`, an opaque word), as an interface call's already
  did.
- **A2, `len`.** `len` of a value that is not a string or a byte slice (the rendering holds a slice, map, channel or
  array as an opaque word) is the opaque call `["call", "len", x]`. By A-env it is a function of its argument. It is
  never `["len", w]`, the byte length of a word.
- **A2', after run 1.** Run 1 showed `len` of *strings* the rendering holds as a word or as a storage view (c08, and
  c18's `v:Address`). In a Go machine document, the model now makes such a length a free value: an environment member
  keyed by the term. This is not in the counted run (Surprises, 1).
- **A3, whole-string writes.** In a Go machine document's structural store (an abstract cell per field, whose string
  content no read of the model decodes), a whole-string write writes the cell with a free environment member keyed
  by the written term. It still touches the slot.
- **A4, whole-map writes.** These stay refused: no finite store says "every key reset", and a havoc of a map family
  would need every later read of it to be free.

**(c) SG1.** Below 2^255, the two's-complement order of 256-bit words is their unsigned order. So a signed comparison
whose two operands are provably below 2^255 takes the unsigned comparison's sign. The operands that qualify:
- a literal below 2^255;
- `trunc` to at most 255 bits;
- a `len`;
- a boolean operator;
- a register read of a path declared bool, address or uint<N> with N < 256 (`Layout.narrow`).

Every other signed comparison stays `?`. Notably, a `sext` operand can be negative, and so can a 256-bit register.

**(d) Opaque keys.** In a Go machine document, a string- or bytes-keyed step's key word is a free environment member
of the step:
- A key whose compiled code reads no state view is keyed by its code, so syntactically equal keys share one word.
- Any other key gets a member of its own.

The members are free, so no two keys are ever equated or ordered to prove anything. A read after a write to a
syntactically different key is unconstrained.

**(e) The budget.** A transitions sidecar may name `term_budget`. The walker renders under it, and the document
records it. A sidecar without the key renders under TERM_BUDGET (400000) and writes no key, so its document is byte for
byte as before. The I109 protocol names the M6 tier, 4000000 (10×). A term over the tier is still an extraction error
that names the budget. Nothing is dropped, and nothing is split: splitting per action changes no term's size.

**(f) Remapped pragmas.** `unit_pragmas` follows each non-relative import through the sidecar's remappings, as solc
resolves them: the longest matching context wins, then the longest prefix. So a remapped dependency's pragma takes
part in choosing the release. A wrong choice can only fail the compile.

**(g) The constructor rule and Q64's default.**
- `machines.nil_maps` is `"unknown"` unless the config says `"zero"`. That is the only opt-out, and every document
  records the mode in `extraction.machines`.
- Under `"unknown"`, a map field of T is non-nil in R0 only if all of these hold:
  - T has a constructor: a function of the document's packages, not a method, returning T or *T;
  - on every return of every constructor that yields a T, the returned allocation does not escape (it is used only
    to address its fields, be loaded or be returned);
  - the field's address is only stored to;
  - every store to it is a MakeMap result, and one such store dominates the return;
  - no action writes the field whole.
- Every element write into any other map field is nil_map debt, and the typed model refuses the document.

## Soundness

1. **A1 adds no behaviour and removes none.** The receiver was already a term argument. Only the signature's arity
   now matches it, so the call is encoded rather than refused. The answer stays a free function of its calldata (A-env).
2. **A2/A2' and A3 are havocs.** A length or a written string becomes a free value, keyed by its term. Equal terms
   in one step denote equal values: the IR's state reads are pre-state, and Go machine documents have no iterated
   loops (A-loop). Distinct terms are independent. The real value is one valuation of the free member, so every
   behaviour of the code is a behaviour of the model, and a PROVED law holds for it. Nothing about string content is
   guessed: the cell is the only thing the model holds of a Go string.
3. **A4 stays refused**, so a whole-map write is never approximated.
4. **SG1 is exact where it applies.** Below 2^255 the signed and unsigned orders coincide (checked on 20000 random
   words, `TestSignedSign`). D9 then uses the unsigned rule it already trusts. Everywhere else the answer stays `?`,
   which only makes a write "unsafe", the conservative side.
5. **Opaque keys over-approximate.** Two keys share a word only when their code is the same pure function of the
   step's context, and then they are equal. Every other pair is free: the solver may make them equal or not, so a
   proof must hold either way. No key is ordered. A key reading a state view gets its own member, so a key never
   aliases across views. (d) applies only to Go machine documents (R4: Morph has none).
6. **The budget never drops a term.** Over the budget is an extraction error that names it; under it, the rendering
   is the same code. A sidecar without the key is byte-identical (R2).
7. **The constructor rule may only remove debt where a made map is proven on every constructor return.** It requires
   a non-escaping allocation, MakeMap-only stores and a dominating store. Anything else keeps the debt, and a
   document with debt is not compiled: its laws are UNKNOWN. Without a constructor, R0 is the zero value, so a map
   field is nil. Q64's default makes this the rule for every Go machine document. The opt-out is explicit and
   recorded.
   - Disclosed limit: exported fields can be set by code outside the machine. The model's actions are the type's
     methods only, as for every field (I105).
8. **Q62 is empty, not invented.** A missing link sidecar gives no roles, no codec component and no codec law, so
   nothing is PROVED through it. A link sidecar that exists is read and checked as before.
9. **REFUTED still needs its replay.** Nothing here touches the refuter or the replay. The smoke runs stop after
   derive and record no verdict.
