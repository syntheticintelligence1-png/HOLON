## Surprises

1. **The nitro Go entries fail on the go directive, not on generated code.** The prediction's reason was "packages that
   import generated code". The actual failure: `go.mod requires go >= 1.25 (running go 1.24.7; GOTOOLCHAIN=local)`,
   for c01, c07 and c12 alike. The outcome held; the reason was wrong.
2. **The optimism Solidity entries fail on an exact pragma, not on remappings.** The prediction's reason was
   "imports need remappings". The actual failure: `pragma solidity 0.8.15` against the pinned 0.8.24. Remappings were
   never reached.
3. **wormhole fails through the protocol's go.work rule.** wormhole's node module replaces `../sdk`, which replaces
   `../wormchain`. The generated workspace therefore uses all three modules, and Go refuses it: "conflicting
   replacements for github.com/cosmos/cosmos-sdk". With the module directory alone, the relative replace leaves the
   tree. Resolving the conflict would mean picking a version, which is a judgment, so this stays a reasoned miss.
4. **One Go document is 3.9 GB** (c18's x/group package root). The extraction finished in about 5 minutes. It is
   recorded by sha256 and size only, under the protocol's 1 MB store limit.
5. **A record's filter_bin can read "finding" when nothing replayed.** On the toy probe, a REFUTED DISCH record with
   replay `not_applicable` (no binding) carries `filter_bin: "finding"` and witness_provenance `internal_harness`. S4
   ignores filter_bin and classes by replay status, so I51 is unaffected. It may matter elsewhere.
6. **The probe's `holon run` over a DISCH milestone decided only the DISCH laws.** The typed (SYM) laws needed a
   second `run --laws`. The protocol had already fixed two runs.

     c01, c07 and c12. That means a scratch config per entry naming another pinned binary.

     session's attempt to download solc 0.8.15 for an unscored counterfactual was refused by the environment's
     permission policy, so it is not known whether those entries would then derive laws.
   - Should a later iteration (an I51b) amend the protocol to pick, per entry, a pinned compiler that satisfies the
     pragma?

   roles and link roles. 14 of the 20 entries are Go. A generator of those sidecars, for example pairing go.codecs

   against something?
