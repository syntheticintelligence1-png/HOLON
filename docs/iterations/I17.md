The four runs are re-encoded as `["const", 0, 0, 4]` (expected cells unchanged); the helper and the test are untouched. Logged in `spec/M2/amendments.jsonl` (iteration I17, kind instrument_defect, test `tests_m2/test_extract_solidity_toy.py::TestToyExtraction.test_toy_layouts_per_selector`). The prereg audit notes the fixture change ("sidecar changed after prereg") for I17 and I18.
2. **W9, one reading made explicit.** W9 decides a condition "when adding it makes the path infeasible". The walker also decides it true when adding its negation makes the path infeasible, so no infeasible branch is walked. With the one-directional reading the Morph and toy documents are byte-identical (checked by running both readings).
3. **Process arguments and the audit hook.** Passing the toy's absolute source path as `--base-path` failed `test_the_toy_extraction_opens_only_the_toy`: the hook requires every in-repo process argument to start with an allowed prefix, and the toy prefix ends in `/`. solc now runs in the source tree with `--base-path .`; spans, unit names and output are unchanged.
4. **Not predicted as a difference, but visible:** the frozen `A-width` and `A-version` assumptions name five fields (batchIndex, l1MessagePopped, totalL1MessagePopped, lastBlockNumber; version); the code needs a width obligation for two only (batchIndex and totalL1MessagePopped are uint256 locals stored as `shl(192, x)`; l1MessagePopped is a uint16, lastBlockNumber a uint64, version a uint8).
