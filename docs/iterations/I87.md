## The 40 degenerate inhabitants, and I45's prediction

BUILD_PLAN I45 predicts "the A4 round flags no degenerate inhabitant". The 40 here are not relabelled to fit that prediction. I45 will be judged on them.

### 1. What "degenerate" means here

**The rule.** The rule was fixed before any outcome, in `spec/M3/lib/audit_loop.json` (`vacuity.degenerate_rules`) and the contract (rules V5 and D1-D3). It applies only to a premised, PROVED law that G11V counts as inhabited (`non_vacuity.status == "inhabited"`). The stored inhabitant (`non_vacuity.witness`) is degenerate when one of these holds:
- **D1** (a law with a State or Reach binder): its state is the model's initial state. A `{steps}` witness has one step, the law's own; a `{prefix, x}` witness has an empty prefix.
- **D2** (two state binders): its two runs are identical. A `{prefix, x}` witness names one run that is used for both.
- **D3** (no state binder): every byte the premises leave free is zero. The premises' field equalities form classes, and a pin fixes its class.

**The code path.** In `holon/audit/vacuity.py`:
- `a4()` calls `classify()` for each law;
- `classify()` calls `holon.inhabit.premised`, then the structural part of G11V's checks on the record, then `degenerate_rules()`.

**Representatives.** A degenerate inhabitant gets a representative where I87 has a generator for one. That means linked-codec laws only:
- `_Codec.fill`: holon.gen.linked's own "counting" fill, with the law's premise classes applied (`apply_classes`);
- `_Codec.check`: the law's own inhabitant generator (`holon.codecrun.inhabitant`), checked by `holon.inhabit._check` with bend2 and then BendTT, exactly as G11V's inhabitants are.

A representative is **found** iff both kernels accept it and no D-rule holds at it. Other degenerate inhabitants are **not_searched**.

They are degenerate because G11V's codec generator always stores the zero completion: `holon.gen.linked.inhabitant_witness`, "zeros everywhere, the premise classes applied", whose record bound reads "the premise classes at zeros". All 99 premise field terms of the 38 laws resolve in their representatives, and each representative passes both kernels.

### 3. Real, or an artefact?

All 40 are **real degenerate inhabitants of non-vacuous laws**. The stored witnesses really are the zero completion, the same run twice, or a run of one step. Nothing was misread: on every law, holon's classification equals the instrument's independent reading. Ranked by this round's rubric (I21's convention: a degenerate inhabitant with a found representative is not a vacuity finding):

- **The 38 PAR laws:** degenerate stored inhabitants, but **not vacuity findings**. Each premise set provably holds a non-degenerate point: a nonzero completion that both kernels accept. D3 is a deliberately strict rule. A zero header that satisfies a version pin is a legitimate inhabitant; it is the minimal one, and A4 asks for a representative beside it. No finding is filed.
- **The 2 state laws:** real, open, and **filed as finding F-M3-01 (medium)**.
  - For the FACT kernel law: the inhabitant only shows the premise holding on two identical runs, where it holds trivially. Whether two different runs agree on the commitment is undecided.

  - Neither law is vacuous (G11V passes), so this is not high. A4's representativeness duty is undone for them until the I45 round's state-law search runs.
