## Goal

Derive the header layout of the Solidity commit path from what the compiler produces, not from a transcription. Compile `Rollup.sol` at the pinned commit with the pinned solc (AST only), walk the entry function symbolically through the Solidity AST and the Yul AST of every inline assembly block, inline the library store functions, and record every memory write into the region whose `keccak256` is the selected sink. Write `spec/M2/facts/morph_header.extracted.json` (holon-facts/0.3), byte-identical across runs and regenerated by G1. Then compare it with the frozen `facts/morph_header.json` through the frozen reference interpreter: that comparison is what the predictions score.

## Rules

- **Never tune to a prediction.** A layout difference is either a finding about the frozen facts or an extractor bug (BUILD_PLAN I17 risks): raise a Question, never edit `facts/` or the sidecar, never special-case an edge, a function, a span or a constant. P3 is predicted to show a real difference from the frozen facts: report it as a Question for the human, do not "fix" it.
- **No target vocabulary in holon/frontends.** No Morph name, revert text, span, 249 or 257, docstrings and comments included (`test_extract_solidity_honesty.py`), and no `morph` in code anywhere in `holon/` (`test_target_agnostic_exhaustive.py`). The config key is generic (`extract.sources`), the target lives only in the sidecar.
- **The extraction reads the compiler's output and the source tree only.** No fact document, law, result, generated file, IR, bytecode, Slither or z3 (audit-hook test, poisoned-copy test). The frozen facts are read only by the tests, through `tests/reference/ref_model.py`.
- **Debt, never silence.** Every construct outside W6/W7 is a debt entry with havoc (D1), whatever it is; a selected sink never reached, an environment-dependent layout or an inexpressible length is exit 3, never a guess.
- **Determinism.** Sorted keys, the documented orders, canonical src items, no timestamps, no absolute paths, no host names.
- **M0, M1 and the earlier M2 outputs do not change** (R1-R3). The skip in `fact_documents` is what keeps `gen/M2/diagram`, `gen/M2/sorts`, `gen/M2/evidence.json` and, after I15, `laws/M2` unchanged.
