## Goal

- All nine §13 ablations: no sorts-as-types, no writer provenance, no evidence calculus, 2-cycles instead of fundamental
  cycles, no native-equivalence NAT, no enablement in DISCH, no replay, single kernel, and no frozen statements (the
  weakening rate measured by A3 in a sandbox). Each switches off one component and reruns what it feeds, on Morph and,
  where it applies, on the corpus and the held-out target. None is skipped; a component that cannot be switched off
  cleanly is reported with the reason and what was measured instead.
- UNKNOWN calibration on the I48 controls.
- Every §13 metric, with deltas against the baselines wherever a baseline has the metric, each read from a recorded
  result; a metric with no source is missing, with the reason.
- Exit: `results/eval/ablations.json` and `docs/M4_EVAL.md` are generated by a script from the recorded results, and
  every ablation has run.

The contract is the docstring of `tests_m4/test_i53_ablations.py` (B1-B7). The key is `I53` in
`spec/M4/predictions.json` (source `spec/M4/predictions/I53.json`). The protocol is `spec/M4/lib/I53_protocol.json`, the
sandbox prompt `spec/M4/lib/I53_a3_prompt.md`, the independent scorer `tests_m4/_i53.py`.

## What I53 must not change

Nothing in M0-M3: no law, record, result, generated file or record-pinned holon/ file. New code goes into
`holon/eval/ablate*.py` and the command table of `holon/eval/cli.py`; no generator closure imports them. Every switch is
applied in the ablation's own process to a scratch copy outside the repository. The A9 sandbox is a scratch clone
outside the repository, never committed or pushed; frozen files in the repository are never edited and
`tools/freeze.py write` is never run.

## Process

1. Prereg (this commit): the prompt, the key, the protocol, the prompt of the sandbox attackers, the instrument and the
   contract tests; `python -m holon audit prereg --milestone M4` prints PREREG OK; pushed before any ablation run.
2. The adversarial phase, run by the builder: try to make an ablation look harmless or a metric better than its source;
   check that every metric can fail; fold in the fixes (an instrument fix after the prereg is an amendment).
3. Run the ablations concurrently in the container; subagents only for the A9 sandbox.
4. Validate: the new tests and the other M4 keys' tests on the merged tree, freeze check, the CI gates with M0-M3
   unchanged, the target-agnostic scan, the frozen suite if feasible.
5. Report (docs/iterations/I53.md) and the draft PR, first line `I53 ready: <one-line outcome>`.
