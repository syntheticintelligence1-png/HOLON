# I6: remove Morph-specific code from the generators

Rendered from `docs/BUILD_PLAN.md` §4, I6 (V16). Read `AGENTS.md`, `docs/M0_SPEC.md` and `docs/BEND_PRIMER.md` first.

## Why

The model generator (`holon/gen/machine.py`) carries the Morph rollup's library inline:
- the window and challenge helpers (`win_at`, `nth_ch`, `bump_f`, `any_open`, …);
- the ghost-tag and header projections;
- the aggregate stand-in;
- the Go slice and growth library.

The proof generator matches Morph builtin names, and the explorer imports Morph search hints. HOLON cannot target anything else (whitepaper §8.3, §9.7, §13, App. H).

## What to build

1. **Prereg first.** The `I6` key, `tests_m2/test_target_agnostic.py`, the toy machine fixtures in `tests_m2/fixtures/toy_queue/`, and this prompt.
2. **Target libraries** (`holon-lib/0.1`), loaded by facts and declared types:
   - `spec/M1/lib/morph_rollup.lib.json`: builtins as call templates, plus Bend blocks templated on record fields;
   - `spec/lib/go_slices.lib.json`.

   The generator emits library blocks at the positions the old code used, so every generated byte stays the same.
3. **The proof generator** recognises a library list accessor by its declared kind, not by name.
4. **Search hints.** `holon/js/policy_lib.mjs` moves to `spec/M1/policy_hints.mjs`, an untrusted hints module chosen by the facts. Machines without hints use `holon/js/policy_gen.mjs`, which enumerates actions over `facts.search.domains`.
5. **Toy machine.** It runs end to end: the planted true law is PROVED and the planted false law is REFUTED.

## Scope and deviation, stated before results

The plan's grep test covers all of `holon/`. This prereg covers the generic generator modules listed in the test. The replay and target adapters stay where they are:
- `holon/replay.py`, `holon/mreplay.py`, `holon/consumers.py`;
- the `m0_commit_trace` part of `holon/evidence.py`;
- `holon/oracles/`.

They drive Morph's real code by nature, and moving them is listed as debt. Records may differ in `generator_sha256`, which changes by design when the generators change.

## Rules

- Byte identity is the contract. A def that cannot be reproduced byte for byte stays in `holon/` as a named allowlist entry and is reported. It is never re-emitted with different text.
